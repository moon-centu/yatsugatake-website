# 八ヶ岳 滞在コンシェルジュ

リゾナーレ八ヶ岳を題材にした学内提案用・非公式プロトタイプ。ホテル公式サイトの変更やホテルへの実予約は行いません。

## 実装
- 到着・出発時間、1〜3日、同行者、人数、子供の最低年齢、興味、夕食スタイル、天候によるルールベースの日程生成。
- 時間重複を避け、原則15分の館内移動・着替え余裕を追加。館内移動は概算で、ナビゲーション実測ではありません。
- 3つのおすすめプラン、個別の予定追加・削除、全日程の印刷、保存・再読込。
- D1を使ったゲストとスタッフ共通の予約リクエスト。受付・取消、条件検証、時間重複とデモ定員の原子的検査。
- 施設状況のスタッフ更新と10秒間隔での画面同期。自動センサーデータではありません。休止中の体験は新規プランから除外。

## データと権限
現在はリンクを持つ誰もが試せる公開の共同プロジェクトデモです。ゲスト／スタッフを切り替えて予約・受付・取消ができ、確認済みの予約も全参加者がキャンセルできます。名前・部屋番号には架空の情報のみを使用してください。共有予約一覧には内部の所有者IDを返しません。

匿名ブラウザにはサーバー発行のランダムなHttpOnly・SameSite Cookie（7日間）を割り当て、別ブラウザの予定・時間重複チェックを分離します。書き込みは有効なデモ接続Cookieと専用リクエストヘッダーを要し、異なるOriginからの操作を拒否します。公開デモへの参加は誰にでも認められますが、これはホテルの本人確認やスタッフ認証ではありません。実運用ではサーバー側のスタッフ認可、ユーザー単位の予約表示、宿泊者照合、監査、ホテルの在庫・予約API連携が必要です。

予約定員・時間枠はすべてこのプロトタイプのデモデータです。予約状態「デモ確定」はホテル予約を意味しません。共有DBとローカル開発DBは別です。

## 開発
`npm run dev` / `npm run db:generate` / `npm run build`。初回のD1ローカルマイグレーションは生成済みdrizzle SQLを適用してください。

## 表示言語
日本語・မြန်မာ・English・简体中文・한국어に対応。ヘッダーの言語選択でゲスト／スタッフ、保存済みプラン、施設案内、予約フォーム、状態・エラーメッセージを切替可能。選択言語だけをブラウザに記憶し、予約・プラン本体は共有DBに保持します。顧客名・部屋番号・予約IDは翻訳しません。公式施設名はローマ字表記や各言語の説明を併記した表示名を使用しています。外部の公式案内ページそのものを翻訳するものではありません。

共有デモの検証: `node --experimental-strip-types tests/shared-demo.mjs`。実際のAPIハンドラーとSQLiteで、別ブラウザの予約・個別プラン・相互キャンセル・受付・書込み制約を検証します。
